# Hotel Network System

Designed and implemented a complete network for a three-floor hotel.

## Features
- VLANs for each department
- DHCP for dynamic IP assignment
- OSPF routing between routers
- SSH for secure remote access
- Port security configuration

## Tools Used
- Cisco Packet Tracer
- Networking concepts (VLAN, OSPF, DHCP, SSH)

## Verification
- Verified inter-VLAN communication
- Tested DHCP bindings and SSH connectivity
